# Quarto Feedback

Комментарии к коду Quarto одной горячей клавишей: **Cmd+Option+A** на Mac, **Ctrl+Alt+A** на Windows/Linux.

## Как пользоваться

1. Откройте `.qmd` в редакторе исходного текста VS Code или Positron.
2. Поставьте курсор на строку кода либо выделите несколько строк внутри одного блока.
3. Нажмите сочетание клавиш. Выбранные строки получат один общий маркер `# <N>`, а курсор перейдёт к пункту `N. ` под блоком.
4. Напишите замечание прямо в документе.

Повторное нажатие на отмеченной строке выделит текст её существующего комментария. Если часть выделенных строк уже имеет один общий номер, он распространится на остальные выбранные строки. Разные существующие номера не объединяются.

Для каждого блока нумерация начинается заново. Пустые пункты тоже учитываются. Пустые строки и настройки блока `#|` внутри выделения пропускаются. Выделение до начала следующей строки не включает эту строку. Вставка маркеров и пункта отменяется одним действием Undo.

Поддерживаются R, Python/py, Bash/sh и Julia. Язык сообщений следует языку интерфейса редактора: английский или русский.

## Отображение

Для открытия замечания по нажатию на номер добавьте в YAML:

```yaml
format: html
code-annotations: select
```

`hover` показывает замечание при наведении, а `below` — под всем блоком кода. В PDF замечания отображаются под кодом. Заполните пустые пункты перед рендерингом. Для создания HTML/PDF нужен установленный Quarto; сама команда расширения только редактирует документ и не запускает код.

[Документация Quarto](https://quarto.org/docs/authoring/code-annotation.html)

## Установка и переход с локальной версии

После публикации устанавливайте **Quarto Feedback** от **vladissta** через каталог расширений редактора. Также можно выбрать **Extensions: Install from VSIX...** и указать установочный файл.

Если установлена наша прежняя версия от `local-feedback`, сначала удалите её: публичная версия имеет другой идентификатор, но регистрирует ту же команду. Комментарии остаются в `.qmd`.

Если сочетание перехватывает старая настройка `cmd+alt+a` → `runCommands`, удалите только эту привязку из Keyboard Shortcuts (JSON). Команда доступна также через палитру: **Quarto: Добавить или изменить комментарий к коду**.

## Ограничения

- Редактор исходного текста, одно непрерывное выделение внутри одного блока. Несколько курсоров, визуальный и notebook-редактор не поддерживаются.
- Обычные ограждения из обратных кавычек или тильд, отступ до трёх пробелов. Блоки, вложенные в списки или цитаты, не поддерживаются.
- Автоматической перенумерации при удалении и перестановке нет. Список должен идти последовательно: `1.`, `2.`, `3.`. Нумерованный список сразу после кода считается списком аннотаций.
- Продолжения пунктов и дополнительные абзацы сохраняются; при переходе к существующему замечанию выделяется только первая строка текста.
- Расширение не анализирует синтаксис языка. Выбирайте строки, где допустим комментарий `#`; не выделяйте содержимое многострочных строк, heredoc и блочных комментариев. Продолжение строки через обратный слеш блокируется.
- Постоянно открытые карточки справа от кода не входят в этот выпуск.

Расширение не отправляет данные, не собирает телеметрию и не запускает код. Лицензия — MIT.
